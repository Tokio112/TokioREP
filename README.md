# Утренний бот-сводка

Каждое утро присылает: погоду, совет что надеть, планы на день, расписание
пар с точным временем и перерывами, когда выходить из дома / с работы,
и во сколько лечь спать, чтобы выспаться.

Все данные (город, расписание, время в пути и т.д.) бот собирает сам через
диалог в Telegram — команда `/start`. Никакие файлы редактировать не нужно.

## 1. Получить токен бота

1. В Telegram напиши **@BotFather** → `/newbot` → следуй инструкциям.
2. Скопируй выданный токен.

## 2. Получить ключ погоды (бесплатно)

1. Зарегистрируйся на https://openweathermap.org/api
2. Возьми API-ключ (бесплатный тариф достаточен).
   Учти: новый ключ может активироваться до ~1 часа.

## 3. Установка

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env` и впиши туда свои значения:

```
BOT_TOKEN=токен_от_BotFather
WEATHER_API_KEY=ключ_с_openweathermap.org
```

## 4. Запуск

```bash
python bot.py
```

Бот должен работать постоянно (пока процесс запущен — он присылает сводки).
Для круглосуточной работы удобно развернуть его на недорогом VPS, Raspberry
Pi или на бесплатном тарифе сервисов вроде Railway / Fly.io / PythonAnywhere,
запустив `bot.py` как постоянный процесс (или через systemd/screen/tmux).

## 5. Настройка в Telegram

Напиши боту `/start` и ответь на вопросы:

- город (для погоды);
- часовой пояс (например `Europe/Warsaw`);
- время подъёма;
- сколько часов сна нужно;
- во сколько присылать сводку;
- время дороги из дома до колледжа;
- работаешь ли ты, и если да — время дороги с работы до колледжа и во
  сколько работа заканчивается в каждый день недели (или "-", если в этот
  день работы перед учёбой нет);
- расписание пар на каждый день недели — сообщением, каждая пара с новой
  строки, например:
  ```
  9:00-10:30 Матанализ
  10:45-12:15 Физика
  ```
  Если пар в этот день нет — отправь `-`.

После этого бот сохранит настройки и каждый день в выбранное время будет
присылать сводку.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | первичная настройка |
| `/today` | прислать сводку прямо сейчас |
| `/addplan текст` | добавить пункт в планы на сегодня |
| `/plans` | показать планы на сегодня |
| `/clearplans` | очистить планы на сегодня |
| `/settings` | показать текущие настройки |
| `/reset` | стереть все настройки и начать заново |
| `/cancel` | прервать текущий диалог настройки |

## Логика расчётов

- **Совет по одежде** — по ощущаемой температуре, ветру, дождю/снегу.
- **Когда выходить** — время начала первой пары минус время в пути.
  Если в этот день перед учёбой у тебя работа — считается дорога
  работа→колледж от времени окончания работы, иначе дорога дом→колледж.
- **Во сколько лечь спать** — время подъёма минус нужное количество часов сна.
- **Перемены** — считаются автоматически как разница между концом одной
  пары и началом следующей.

## Хранение данных

Данные пользователей хранятся локально в файле `data.json` рядом с `bot.py`
(создаётся автоматически). Отдельного сервера базы данных не требуется.
